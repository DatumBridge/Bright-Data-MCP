# Use Cases

| Actor | Goal | Tool |
|-------|------|------|
| Agent | Read a public page as markdown | `scrape_url` with `format=raw`, `data_format=markdown` |
| Agent | Read raw HTML from a page | `scrape_url` with `format=raw` (default) |
| Agent | Find public web results | `search_serp` |
| Operator | Verify config before demos | `bright_data_health` |
